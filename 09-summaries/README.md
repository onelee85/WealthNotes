# Summaries

本目录用于：

- 一个 Stage 学习完成后的总结
- 对多个知识点建立联系
- 记录投资认知发生的变化
- 最终形成自己的家庭投资理财框架

学习辅助材料：

- [家庭财务基础：5 分钟速查表](../01-family-finance/family-finance-5-minute-cheat-sheet.md)
- [阶段总结模板](stage-summary-template.md)

阶段总结建议回答：

```text
我学到了什么？
以前哪里理解错了？
哪些知识最重要？
它们之间是什么关系？
哪些内容改变了我的投资判断？
还有哪些问题没有解决？
```

阶段总结应由学习者在完成相应课程后亲自撰写，不预先生成个人结论。

从 Stage 2 开始，完成阶段后复制模板并使用 `stage-xx-topic.md` 的英文短横线文件名。总结应控制在 5 分钟可复习的长度；AI 可以协助整理事实、概念关系和自测题，但“我的认知变化”和“对我的投资启示”必须由学习者本人填写。
