# 学习闭环

本知识库使用“路径 → 核心 → 测试 → 纠错 → 复述 → 课内总结 → 证据 → 压缩 → 复习”的学习闭环。这个方法参考了 [How To Learn Anything 10x Faster Using Claude](https://x.com/sairahul1/status/2068250224532050089) 中关于学习路径、主动测试、一页压缩、资源筛选和反馈循环的建议，但不承诺“10 倍速度”或固定时数内掌握。

现有六个 Stage 就是学习路径，不再额外叠加五级课程。学习时长不固定；是否进入下一课，由可验证的掌握证据决定。

## 每课流程

1. **定位路径**：确认当前课程、前置知识、Learning Goals 和阶段进阶证据。
2. **抓住核心**：优先学习会影响家庭财务判断的概念，不追求金融百科式完整。
3. **闭卷测试**：合上笔记，一次只回答一题；每课完成 2 道概念题、2 道虚构情境应用题和 1 道反例或边界题。
4. **精确纠错**：只解释答错或遗漏的部分，再用一道替代题验证，避免“看懂答案”被误认为“已经掌握”。
5. **费曼复述**：由学习者用自己的话解释；若仍有缺口，继续纠错和复述。
6. **课内总结**：费曼复述通过后，补充当前课程文件中已验证的核心定义、公式及适用条件、虚构或去敏案例和常见误区；把学习者已经确认的“我的理解”写入相应位置。只增补本次实际学过的内容，不预填未学课程正文。
7. **留下证据**：在课程文件中记录覆盖的 Learning Goals、重要错误、纠正结果和下一复习触发点。
8. **阶段压缩**：完成一个 Stage 后，使用[阶段总结模板](../09-summaries/stage-summary-template.md)整理一份可在 5 分钟内复习的总结。
9. **事件复习**：按照[复习队列](review-queue.md)在后续独立学习会话、阶段结束和进入下一阶段时重新检索，而不是反复通读正文。R1 不在同一学习时段即时执行；应在完成上一课后至少隔一个自然日的下一次独立学习会话中进行。

## 掌握标准

- `NOT_STARTED`：尚未开始课程。
- `LEARNING`：已经开始学习，但掌握证据尚不完整。
- `UNDERSTOOD`：每个 Learning Goal 都至少有一次正确的闭卷回答；重要错误已经纠正并通过替代题；能够用自己的话准确、简洁地解释本课主题。
- `APPLIED`：在 `UNDERSTOOD` 基础上，独立完成一个新的虚构或彻底去敏案例，并说明判断过程和适用边界。

Stage 1 已有的 `UNDERSTOOD` 状态保持不变；以上证据门槛从 Stage 2 开始使用，不追溯重开既有课程。

## 学习资源预算

每个 Stage 同时使用的主要资源不超过 5 个，并在开始该 Stage 时再选择：

1. 优先监管机构、产品发行文件、官方说明、教材或其他一手来源。
2. 每个资源必须写明它解决什么问题，以及在什么顺序使用。
3. 同一功能只保留最清晰、最可靠的资源，避免把收集资料当成学习。
4. 涉及可能变化的规则、产品信息或数据时，记录来源日期并重新核实。
5. 资源用于理解，不用于让 AI 替学习者形成个人投资结论或策略。

## AI 学习边界

AI 可以出题、逐题反馈、指出知识缺口、解释事实和提供虚构案例，但必须遵守以下边界：

- 每次只出一题，等待学习者作答后再反馈。
- 不先展示标准答案，不用总分掩盖具体知识缺口。
- 答错时只重教缺失部分，并以替代题重新验证。
- 不代写“我的闭卷复述”“认知变化”“对我的投资启示”或个人投资策略。
- 进行课内总结时，只记录已验证的事实、公式、适用边界和虚构或去敏案例；学习者专属字段只引用或轻度整理其已确认的表达，不自行补写个人结论。
- 不索取或保存账户、余额、真实持仓、交易明细、身份信息等敏感数据。
- 案例只使用明确标注的虚构数据，或由学习者彻底去敏后的抽象情境。

## 七个精简脚本

以下脚本不绑定特定 AI 工具。将方括号内容替换为当前 Stage 或课程即可。

### 脚本 1：定位学习路径

```text
请以本知识库的学习路线为唯一主线，帮助我定位 [当前课程]。
告诉我它依赖哪些已经学过的概念、Learning Goals 中最重要的能力、
本课完成后应留下什么掌握证据，以及下一课会如何用到它。
不要重新设计课程路线，也不要提前扩展后续课程正文。
```

### 脚本 2：提取核心能力

```text
请从 [当前课程] 中找出最影响家庭财务判断的少数核心概念。
说明这些概念之间的关系、必须避免的误解，并给出一个简单的虚构练习。
省略不影响当前 Learning Goals 的历史、术语堆砌和专业细节。
不要替我形成个人投资启示或策略。
```

### 脚本 3：闭卷测试

```text
请作为严格但友善的考官，根据 [当前课程] 的 Learning Goals 测试我。
总共准备 2 道概念题、2 道虚构情境应用题和 1 道反例或边界题，
但每次只问一题并等待我的回答，不要提前展示答案。
每次反馈请指出：答对的部分、确切缺口、只针对缺口的解释。
若有重要错误，先出一道同目标的替代题；答对后再继续。
最后逐项说明哪些 Learning Goals 已有闭卷证据，哪些仍需复习。
```

### 脚本 4：阶段压缩

```text
请根据 [当前 Stage] 已完成的课程，协助我使用阶段总结模板制作 5 分钟复习卡。
只整理事实、概念关系、公式、常见误区和 5 道快速回忆题，保持简短可扫描。
“认知变化”和“对我的投资启示”必须留空，由我本人填写。
如果课程笔记之间有矛盾，请标出矛盾，不要自行掩盖。
```

### 脚本 5：筛选学习资源

```text
请为 [当前 Stage] 筛选最多 5 个高价值学习资源。
优先权威或一手来源；对每个资源说明类型、解决的问题、使用顺序、
来源日期和不值得投入时间的部分。涉及会变化的信息时必须核实并给出链接。
不要扩展为完整金融书单，也不要根据资源替我制定投资策略。
```

### 脚本 6：费曼复述

```text
请让我先用自己的话解释 [当前课程]，不要替我起草答案。
收到我的解释后，分别指出正确部分、遗漏、错误和边界不清之处，
只重教我没有掌握的部分，再让我重新解释。
重复直到表达简洁、准确，并覆盖全部 Learning Goals。
结束时只提醒我把自己的最终复述写入课程笔记，不要代写个人投资启示。
```

### 脚本 7：整理当前课程笔记

```text
本课的闭卷测试、纠错和费曼复述已经完成。请把已验证的内容补入 [当前课程文件]：
1. 核心定义、公式、公式的适用条件和边界；
2. 本次使用的虚构或彻底去敏案例及其计算；
3. 已验证的常见误区与纠正；
4. 我已经确认的“一句话理解”或闭卷复述。

只补充本次实际学习过的内容，保留课程模板和学习证据。不要预填未学内容，
不要代写“为什么对家庭理财重要”“对我的投资启示”或新的个人观点。
```
