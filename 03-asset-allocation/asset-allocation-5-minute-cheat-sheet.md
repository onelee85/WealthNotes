# 资产配置：5 分钟复习卡

> 用途：在比较产品或调整组合前，先确认每类资产的角色、风险来源、底层重合、目标约束与再平衡规则。

![资产配置：5 分钟速查图](asset-allocation-5-minute-cheat-sheet.png)

## 一句话模型

资产配置是先按家庭目标、期限、流动性需求和风险承受能力确定组合框架，再用分散与再平衡让实际风险尽量不偏离这个框架。

## 关键概念与联系

| 概念 | 最简单的理解 | 与其他概念的联系 |
|---|---|---|
| 资产类别 | 按风险和收益来源归类的底层资产 | 产品名称不等于资产类别，须穿透看底层。 |
| 资产角色 | 每类资产在组合中承担的功能 | 角色不是收益或安全保证，仍需看具体风险。 |
| 分散化 | 不把结果过度押在单一风险来源上 | 需检查底层重合；分散降低集中风险，不能消除整体市场风险。 |
| 目标配置 | 各类资产的目标比例 | 由目标、期限、流动性和风险承受能力约束，不由近期表现决定。 |
| 比例漂移 | 实际比例因涨跌或现金流偏离目标 | 漂移可能改变组合的风险特征。 |
| 再平衡 | 按规则让实际比例回到目标附近 | 可按时间、阈值或新增资金进行，并须权衡成本与流动性。 |

## 关系图

```text
家庭目标 + 使用期限 + 流动性需求 + 风险承受能力
                         ↓
                    目标配置
                         ↓
资产类别与角色 ──→ 组合风险来源 ──→ 穿透检查底层重合
                         ↓
                市场涨跌 / 新增或取用资金
                         ↓
                     比例漂移
                         ↓
     阈值、交易成本、税费、流动性、退出限制 → 再平衡方式
```

## 重要公式或判断问题

- 先问：每类资产的底层是什么？它在组合中承担什么角色？
- 再问：资金何时必须使用？到期时能承受多大波动与流动性限制？
- 检查：实际比例是否已达到预设再平衡阈值？
- 若要调整：新增资金能否优先补入占比偏低的资产？交易成本、税费和退出限制是否值得立即交易？
- 不以近期表现推断未来，也不把再平衡当作短期择时。

## 三个常见误区

1. 基金名称不同就认为已分散，忽略底层公司、行业或地区的高度重合。
2. 只因近期表现好就提高某类资产比例，忽略家庭目标、期限、流动性和风险承受能力。
3. 把再平衡当成对市场反转的预测，或在很小偏离时无视交易成本而立即交易。

## 五个快速回忆问题

1. 为什么产品名称不同不代表真正分散？
2. 目标配置至少应先考虑哪四类家庭约束？
3. 股票从目标 60% 漂移到 68%，说明了什么？
4. 再平衡可按哪三种方式进行？
5. 为什么“卖高买低”本身不能证明是在做纪律性再平衡？

<details>
<summary>答案与纠正</summary>

1. 两个产品可能持有相同公司、行业或地区，风险来源仍高度集中。
2. 目标、期限、流动性需求和风险承受能力。
3. 相对涨跌或现金流使实际组合风险偏离了既定目标，应按规则检查是否需要调整。
4. 按时间检查、按偏离阈值检查、利用新增资金调整。
5. 再平衡依据既定比例与规则；若依据对短期涨跌的预测交易，则是择时。

</details>

## 薄弱点与纠正

| 原来的缺口或错误 | 纠正后的理解 | 验证方式 |
|---|---|---|
| 将新增资金再平衡理解为预测上涨资产会下跌。 | 新增资金可补入低配资产，减少卖出及交易成本、税费或流动性摩擦；不依赖市场预测。 | 替代题：在股票偏高、债券偏低时，正确选择将新增资金投入债券。 |
| 将短期择时简化为“涨时卖、买低价资产”。 | 核心区别是是否基于短期价格预测；纪律性再平衡按既定目标和规则执行。 | 费曼复述纠正后通过。 |
| 只要比例偏离就应立即卖出交易成本高的资产。 | 还要比较比例改善与交易成本、流动性、退出限制，并可在适用时等待新增资金。 | Stage 3 综合虚构案例替代题通过。 |
