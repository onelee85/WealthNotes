# 收益评价

## Learning Goals

完成本课后，我应该能够：

- 区分金额收益、区间收益、年化收益和实际收益

- 判断不同现金流条件下的收益数字是否可以直接比较
- 结合风险和家庭目标评价结果，而不是只看是否盈利
