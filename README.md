# WealthNotes

我的家庭投资理财学习知识库。

本项目不追求让我成为金融专业人士，而是帮助我建立足够用于管理家庭资产的投资理财知识体系。这里只记录金融知识、学习笔记、虚构教学案例、投资方法与反思，不保存真实家庭金融数据，也不提供自动化投资建议。

- `09-summaries` 用于完成阶段学习后的总结与知识连接。

完整课程安排见 [学习路线](00-roadmap/learning-roadmap.md)，当前进度见 [学习进度](00-roadmap/progress.md)，学习中出现的术语记录在 [术语表](00-roadmap/glossary.md)。

## Learning Principle

1. 理解优先于记忆。
2. 决策价值优先于知识完整性。
3. 使用自己的语言记录。
4. 不追求预测市场。
5. 不因为短期涨跌频繁修改长期认知。
6. 每个重要知识最终都应该回答：“它改变了我的什么投资决策？”

## 使用边界

- 这是个人学习知识库，不是金融百科、投资建议系统或交易系统。
- 课程正文应在实际学习时逐步填写，不批量生成完整教材。
- “对我的投资启示”必须由学习者本人形成。
- 案例使用虚构信息或去敏后的抽象描述，不记录账户、余额、持仓金额、交易明细或身份信息。
