# 风险与收益：5 分钟复习卡

![风险与收益一页式速查图](stage-02-risk-and-return.png)

> 本卡只压缩 Stage 2 已验证的事实、公式、判断问题与常见误区；“我的认知变化”和“对我的投资启示”保留给学习者填写。

## 一句话模型

收益不能脱离路径、风险、时间和家庭约束单独判断。

## 关键概念与联系

| 概念 | 最简单的理解 | 与其他概念的联系 |
|---|---|---|
| 收益与复利 | 每期结果会改变下一期的计算基础。 | 路径不同，即使平均收益相近，结果也可能不同。 |
| 波动 | 价值或收益上下晃动的幅度。 | 波动不是亏损本身；可能干扰资金用途与持有纪律。 |
| 最大回撤 | 从峰值到随后低点的最深累计跌幅。 | 描述下行体验，须结合期限及是否会被迫卖出。 |
| 风险承受能力 | 客观上能承受多少损失与波动。 | 受用途、期限、收入、储备、负债和保障约束。 |
| 风险容忍度 | 心理上受不受得了不确定性与下跌。 | 需要压力情景检验，不能用涨跌时情绪代替判断。 |
| 常见风险 | 损失可能从市场、信用、利率、流动性、通胀或汇率而来。 | 比较产品时须同时看收益来源与损失情景。 |

## 关系图

```text
收益路径 → 复利结果
            ↑
波动 → 最大回撤 → 是否影响必要目标 / 被迫卖出
                         ↑
          风险承受能力（客观约束） + 风险容忍度（心理反应）
                         ↓
             识别风险来源、分散或转移，不忽略风险
```

## 重要公式或判断问题

- `期末值 = 本金 × (1 + 收益率)^期数`
- `最大回撤 =（峰值 − 随后低点）÷ 峰值`
- 资金何时必须使用？下跌会不会影响必要目标或导致被迫卖出？
- 收益来自哪里？什么情景下可能损失？

## 三个常见误区

1. 波动大不等于收益更高；低波动也不等于安全。
2. 历史最大回撤不是未来下跌的上限。
3. 分散、担保或主观上“受得了”都不等于风险已消失。

## 五个快速回忆问题

1. 为什么平均收益相同的两条路径，复利结果可能不同？
2. 最大回撤怎样计算？
3. 风险承受能力和风险容忍度有什么区别？
4. 为什么固定票息债券在利率上升时价格可能下跌？
5. 分散和转移风险的区别是什么？

<details>
<summary>答案与纠正</summary>

1. 每期收益或损失改变下一期的计算基础；下跌后需要更高涨幅才能恢复。
2. 用峰值为分母：`（峰值 − 随后低点）÷ 峰值`。
3. 前者是家庭在不损害必要目标下的客观能力，后者是心理接受程度。
4. 新债可能提供更高票息，旧债相对吸引力下降，价格可能需要下调。
5. 分散降低单一事件影响；转移由担保方或保险方承担部分责任，仍须检查其履约能力。

</details>

## 薄弱点与纠正

| 原来的缺口或错误 | 纠正后的理解 | 验证方式 |
|---|---|---|
| 将最大回撤答为金额差。 | 以峰值为分母，结果通常为百分比。 | 虚构峰值 200、低点 150 的替代题。 |
| 认为稳定收入足以让短期必用资金承受大回撤。 | 严格期限与被迫卖出风险不能被稳定收入自动消除。 | 虚构一年后必须支付款项的情境。 |
| 把低波动或担保当作安全证明。 | 仍须检查信用、流动性及担保方履约能力。 | 虚构企业借款违约与第三方担保情境。 |
| 把历史累计收益和表面平稳净值用于推断未来排序。 | 历史路径只能描述已发生的表现；信息不完整时不能跨产品排序，也不能据此断言未来收益或绝对安全。 | A、B 两条收益路径与低波动产品 C 的 Stage 2 综合替代题。 |
